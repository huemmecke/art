# Parameterliste für ArchiCAD

Beim Anlegen des Library-Objekts diese Parameter anlegen (Typen wie angegeben).

| Name | Typ | Default | Beschreibung |
|------|-----|---------|--------------|
| `A` | Length | `4.20` | Gesamtlänge (Bug–Heck) |
| `B` | Length | `2.40` | Gesamtbreite |
| `ZZYZX` | Length | `3.20` | Gesamthöhe inkl. Mastbereich |
| `gs_detlevel` | String | `Mittel` | Detailstufe: Einfach / Mittel / Hoch |
| `matHull` | Material | Metall – Stahl | Rumpf |
| `matPlate` | Material | Metall – Stahl | Panzerplatten |
| `matCabin` | Material | Holz – Lackiert | Kabine |
| `matGlass` | Material | Glas | Fenster |
| `matDetail` | Material | Metall – Messing | Mast, Reling, Details |
| `matFlag` | Material | Stoff | Wimpel |
| `matFigure` | Material | Kunststoff | Maßstabsfigur |

Materialnamen an die installierte ArchiCAD-Materialbibliothek anpassen (VALUES im Parameter-Script).
