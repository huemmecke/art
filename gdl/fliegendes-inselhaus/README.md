# Fliegendes Inselhaus — semantisches 3D-Modell

Konstruktionszeichnung *Fliegendes Inselhaus mit Luftboot* als glTF mit Bauteil-Semantik.

## Korrektur

Die fälschlich modellierte **Rakete** an der Südfassade wurde durch einen **großen Propeller** ersetzt (Nabe, Spinner, 4 Blätter, Welle, Lager, Halter, Ring).

## Vorschau

[`index.html`](./index.html) — Orbit, Bauteilliste, Explosion, Auto-Drehen.

## Dateien

| Datei | Inhalt |
|-------|--------|
| `inselhaus.json` | glTF (eingebetteter Buffer) |
| `index.html` | Three.js-Viewer |
| `referenz-zeichnung.jpg` | Konstruktionszeichnung |
| `replace_rakete_with_propeller.py` | Reproduktion der Rakete→Propeller-Umwandlung |
